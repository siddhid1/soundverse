Webhooks

Every enabled endpoint receives all event types for the account. Filtering and dedupe happen in your receiver. One song produces this sequence over 40–60s: generation.created → generation.progress (25/50/75) → generation.succeeded.

Register endpoint

Registering localhost when the dispatcher runs in docker is the #1 cause of silent delivery failures — from inside the container that address is the container itself.

Local receiver

# terminal 1 — verify signatures, dedupe, filter WEBHOOK_SECRET=<signing secret below> npm run hooks:receiver 9499 -- --events generation.progress,generation.succeeded # terminal 2 — dispatcher logs each delivery npm run start:webhooks # then generate a song on the Generate tab

Deliveries are HMAC-signed (sv-signature over "<timestamp>.<raw body>", 300s tolerance, stable sv-event-id for dedupe). Retries use exponential backoff and dead-letter after the attempt budget — a failed webhook never rolls back the job or its billing.
